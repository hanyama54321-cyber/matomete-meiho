# 名豊興運版 デザイン指示書（v3-M 名豊カラー）

作成: 2026-10-15（準備室チャット）／作成者: 南野（HI-LINE）

名豊興運のトラックと社屋のカラーリング（白い車体・段付きの青帯・細いネイビー線・赤の社名文字）から配色を決めた。**会社ロゴは使わない。**

## 配色トークン

| 役割 | 色 | 由来・用途 |
|---|---|---|
| ベース背景 | `#F4F7FA` | 白い車体・社屋の壁 |
| メイン（メイホーブルー） | `#2290CE` | 車体の帯・運転席。面（ヘッダー帯・アイコン）で使う |
| ディープブルー | `#0B6AA6` | 社屋の帯。白文字を載せるボタン、リンク文字 |
| スカイ | `#63B8E8` | グラデーションの淡い側 |
| ネイビー | `#24366B` | 車体の細い帯。窓・濃い面・お知らせ帯 |
| ネイビー濃 | `#1B2A55` | アイコンのタイヤ・ネイビー単色版の地 |
| レッド | `#D6333F` | 社名文字。アクセント専用（M・重要なお知らせ・未読バッジ） |
| 本文の文字 | `#1B2645` | ネイビー寄りの濃色 |

グラデーション（アイコン地）: `#0B6AA6 → #2290CE → #63B8E8`（135°）

## 使い方のルール

- 白文字を載せるボタンは `#0B6AA6`（白とのコントラスト比 約5.8:1）。`#2290CE` の上の白文字は約3.5:1 なので大きな文字（24px以上）に限る
- 赤はアクセント専用。広い面には使わない（白地で約4.8:1）
- 本文の文字は `#1B2645`（白地で約14.9:1）
- A-LOGI版の赤（メイン色）は名豊のブルーへ置き換える。未読の赤点などの警告色はメイン色と区別して扱う

## アイコン

| ファイル | 用途 |
|---|---|
| `icon.svg` | メイン（ブルーグラデーション）。アプリ内ロゴ |
| `icon-64.svg` / `icon-48.svg` / `icon-32.svg` / `icon-16.svg` | 小サイズ用（回路ライン・ホイール等を段階的に省略済み） |
| `icon-navy.svg` | ネイビー単色版（暗い背景向け） |
| `icon-mono.svg` | モノクロ（印刷用） |
| `png/icon-192.png` / `png/icon-512.png` | PWA manifest 用（角丸・透過） |
| `png/apple-touch-icon-180.png` | iOS ホーム画面用（角丸なし・全面塗り。角丸はiOSが付ける） |
| `png/favicon-32.png` | ファビコン |

- 形は HI-LINE版 v3 と同一（トラック＋回路ライン）。中央の文字は H → M（赤）
- 荷台から運転席まで「段付きの青帯＋細いネイビー線」を通している（実車の塗り分け）
- 黄色のヘッドライトは外した（配色を白・青・ネイビー・赤の4色に絞るため）
- PNG の書き出し形式（角丸の有無・maskable 指定など）は A-LOGI版の manifest に合わせて調整してよい。必要なら SVG から書き出し直す
- SVG 冒頭の著作表示コメントは消さない
